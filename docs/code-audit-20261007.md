### 前台命令的行为

- `watch` 会控制风扇，需要 sudo；启动前须退出菜单栏应用。运行中的应用会使它在写风扇前报错，避免两套曲线同时运行。
- `watch --interval` 范围为 0.01–5 秒，避免非有限值或极端间隔进入控制定时器。
- 校准仅关闭调用用户的应用，确认退出成功后才继续；结束或取消后重新打开。启动/恢复进程失败会被处理。
- 前台命令通过后台登记 CLI 控制，退出时清除自己的控制。未发起控制的 `watch` 会话不会仅因退出就重置风扇。
- Smart 曲线、各模式既有温控阈值及安装方式没有调整。
