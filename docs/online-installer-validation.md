# 在线安装器实现验证（2026-09-30）

基于 0.2.3.32 源码；此记录描述尚未发布的安装器变更，不是另一个 0.2.3.32 发行产物。

## 已完成

- Debug / Release：各 149 项 Swift 测试、24 个 suite 通过；既有断连客户端脚本通过。
- 安装器：15 组 Python 集成测试通过，包含临时发行包与失败分支；不运行真实 sudo、Homebrew 更新或 SMC 写入。
- GUI：实际运行生成的终端启动脚本，验证含空格、单引号、shell 元字符的路径被作为字面参数传入，安装器失败码向上传递，临时目录在成功/失败后清理。
- `shellcheck`：安装器、打包脚本、资源检查脚本通过。
- 本地 Release 打包：App 严格签名验证通过；App 内嵌安装脚本与版本替换后的源码一致，附件直接复制内嵌脚本；压缩包与脚本的两个 SHA256 校验文件均通过。
- 打包保护：语言资源或安装脚本缺失时，组装失败且保留原目标 App 的 sentinel。
- 使用新打包的 `dist/install.sh` 默认版本执行 `--check`，下载边界替换为本地新打包资产，其余路径、摘要、版本、签名检查均真实执行并通过。
- 真实联网：`bash Scripts/install.sh --version 0.2.3.32 --check` 从 GitHub 下载公开发行包，通过 SHA256、归档路径/类型、App 身份/版本/严格签名及 CLI 版本检查。该命令不安装、不停止应用、不改变风扇控制。
