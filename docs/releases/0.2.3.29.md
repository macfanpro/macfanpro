This release adds 14 interface languages, for 17 in total, and makes the README and release notes bilingual. Based on ThermalForge 0.2.3.

## What's changed

### New

- **14 new interface languages**: Japanese, Korean, German, French, Spanish, Italian, Brazilian Portuguese, Russian, Ukrainian, Polish, Dutch, Turkish, Vietnamese and Indonesian, alongside English, Simplified Chinese and Traditional Chinese. Follow System picks the first supported language in your system's language order; the Language menu lists each language under its own name. Translations were made by the maintainer; corrections from native speakers are welcome.

### Improved

- **English README**: the README is now in English, with the Chinese version in [README.zh-CN.md](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md). Release notes are bilingual from this release.

Fan control, curves and protection thresholds are unchanged.

Homebrew 7 needs `brew trust macfanpro/tap` once.

## Upgrading

Quit the menu bar app before updating, then install the new version and reopen it. After a Homebrew update, sync the background service and the app too. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## 中文说明

本次更新新增 14 种界面语言（共 17 种），README 与发布说明改为中英双语。基于 ThermalForge 0.2.3。

### 更新内容

- **新增 14 种界面语言**：日语、韩语、德语、法语、西班牙语、意大利语、葡萄牙语（巴西）、俄语、乌克兰语、波兰语、荷兰语、土耳其语、越南语和印尼语，加上原有的英语、简体中文和繁体中文。“跟随系统”会按系统语言顺序选择第一个支持的语言；语言菜单中每种语言以其本名显示。翻译由维护者完成，欢迎母语用户指正。
- **英文 README**：README 改为英文，中文版见 [README.zh-CN.md](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md)。自本版起发布说明中英双语。

风扇控制、温控曲线和保护阈值未改变。

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。
