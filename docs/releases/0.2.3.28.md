本次更新修正“检查更新”的结果一直显示的问题。基于 ThermalForge 0.2.3。

## 更新内容

### 修复

- **检查结果只在本次打开菜单时显示**：此前按下“检查更新”后，结果（如“已是最新版本”）会一直留在菜单中，之后再打开看到的是过时的结果。现在关闭菜单后，这一行恢复为“更新”；发现新版本时顶部的更新提示仍会保留。正在进行的检查不受影响，完成后照常显示结果。

更新检查的方式、风扇控制与保护阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.28-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.28/MacFanPro-0.2.3.28-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.28/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。Homebrew 更新后仍需同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。
