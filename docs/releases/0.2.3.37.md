This release makes installation and updates easier through a local proxy and gives the MacFanPro icon a cleaner edge. Based on ThermalForge 0.2.3.

## What's changed

### Improved

- **Proxy-assisted installation and updates**: the online installer now detects an enabled macOS HTTPS or SOCKS5 system proxy. The [proxy instructions](https://github.com/macfanpro/macfanpro/blob/main/README.md#update-through-a-proxy) also cover the initial script download for users whose terminal cannot reach GitHub directly. Homebrew installations continue to be managed by Homebrew.
- **Update guidance**: the app adds a proxy hint beside its copyable update command. The update action can use the configured system proxy.
- **Cleaner logo**: removed the soft glow around the fan from the app icon and the extra icon halo in both repository preview images. The fan's gradient and smooth edges remain.

Fan control, thermal curves and protection thresholds are unchanged.

## Download and install

Requires **an Apple Silicon Mac with macOS 14 or later**.

Choose one install method: [Online installer](https://github.com/macfanpro/macfanpro#online-installer) · [Homebrew](https://github.com/macfanpro/macfanpro#option-1-homebrew) · [Release download](https://github.com/macfanpro/macfanpro#option-2-release-download). If GitHub is unavailable in Terminal, use the [proxy command](https://github.com/macfanpro/macfanpro#update-through-a-proxy) and replace the example port with your own.

## Upgrading

On 0.2.3.32 or later, click **Update in Terminal** in the update banner. If GitHub cannot be reached, enable your proxy's macOS system proxy or use the proxy command linked above. Quit the menu bar app before updating. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## 中文说明

本次更新让代理环境下的安装和更新更顺畅，并去掉 MacFanPro 图标周围的模糊光晕。基于 ThermalForge 0.2.3。

### 更新内容

- **代理安装与更新**：在线安装器现在会读取 macOS 的 HTTPS 或 SOCKS5 系统代理。[代理教程](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#使用代理更新)提供覆盖首次脚本下载的完整命令；已有 Homebrew 安装仍由 Homebrew 管理。
- **更新提示**：应用在可复制的更新命令旁提示如何启用代理；终端更新可以使用已配置的系统代理。
- **更清晰的图标**：去掉应用图标中风扇周围的柔光，以及仓库中英文预览图里图标外围的光晕；保留渐变色与平滑轮廓。

风扇控制、温控曲线和保护阈值均未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本) · [Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装)。如果终端无法连接 GitHub，使用[代理命令](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#使用代理更新)，并把示例端口改成自己代理软件的端口。

### 升级说明

0.2.3.32 及以上版本点更新提示中的“在终端中更新”。若无法连接 GitHub，先开启代理软件的 macOS 系统代理，或使用上述代理命令。更新前退出菜单栏应用，详见[更新步骤](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#更新)。
