[中文说明](#中文说明)

Reduce repetitive diagnostics and improve fan-control handback and low-temperature stability. Based on ThermalForge 0.2.3.

## Changes

- Rate-limit ordinary temperature-anomaly reports and collapse consecutive identical process snapshots.
- On quit, stop accepting monitor writes, complete pending commands off-main, and release app-owned control last. CLI holds remain protected.
- Keep a fan's previous target when its automatic-mode write is rejected; preserve firmware readback and recovery.
- Require five sampled cold seconds before normal Smart/curve release, avoiding immediate release after a brief temperature dip. Explicit Default/Silent and safety/failure recovery remain immediate.
- Update displayed readings once per second; profile and control-state changes still update immediately. Control/safety polling remains at 100ms.
- Skip absent temperature probes after complete firmware discovery, rediscover after wake, and add reported sensor keys only on M6 hardware.

## Verification and limitations

Local and hosted CI Debug/Release tests passed (182 tests each). All six downloaded draft assets were verified before publication. Assets were built locally from the tag after a hosted release-runner queue delay; the same source also passed hosted macOS 15 CI.

See the [version validation record](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.67-validation.md). Automated simulation and read-only hardware timing are separate from real fan-control acceptance. M6 fan control and temperature mappings have not been tested on M6 hardware. Packages use ad-hoc signatures and are not notarized by Apple.

## 中文说明

减少重复诊断日志，改善风扇控制交还及低温时的稳定性。基于 ThermalForge 0.2.3。

### 更新内容

- 普通温度波动报告增加限频，重复进程历史合并输出。
- 退出应用时先停止接收监控指令，在后台完成已接收的指令，最后释放应用持有的风扇控制；保留终端控制权。
- 自动模式写入被拒绝时保留风扇之前的目标转速，继续使用固件读回确认和恢复机制。
- Smart 和普通曲线在连续采样低温五秒后才正常释放，避免短暂降温导致立即交还；用户明确选择 Default/Silent、高温保护恢复及失败清理仍立即处理。
- 读数每秒刷新，模式和控制状态变化立即显示；温控及安全检查保持 100ms 周期。
- 完整枚举固件键后跳过不存在的温度键，唤醒后重新发现，并仅在 M6 上补充报告的温度键。
