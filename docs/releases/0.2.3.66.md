MacFanPro continues under its original name and addresses. This release retains the application behavior of 0.2.3.63, with refreshed documentation and screenshots.

## Changes

- Keep the MacFanPro application, command, website and Homebrew names. GitHub remains authoritative; Gitee is a mirror.
- Refresh the repository and website screenshots from the current SwiftUI interface, using labelled sample sensor readings.
- Advance to 0.2.3.66 after withdrawing 0.2.3.64 and 0.2.3.65. Existing MacFanPro users can continue using their normal update entry point.

Fan-control logic, curves and safety thresholds are unchanged from 0.2.3.63.

## Download and install

**Apple Silicon Macs with physical fans, macOS 14 or later.**

**[Download MacFanPro 0.2.3.66.dmg](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.66/MacFanPro-0.2.3.66-macos-arm64.dmg)** — open the disk image, drag MacFanPro into Applications, then open it. For updates, quit the old app first and authorize background-service synchronization if prompted. Homebrew users should continue using Homebrew.
