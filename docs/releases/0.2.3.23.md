本次更新补齐风扇写入失败恢复、并发状态和自动重试问题，并增加可注入故障的回归测试。基于 ThermalForge 0.2.3。

## 更新内容

### 修复

- **写入失败后的恢复**：即使已有手动或满速设置，部分风扇写入失败也会触发恢复；恢复失败会继续重试，后续单风扇指令不能遗失其他风扇的恢复任务。
- **看门狗与高温保护**：判断过期和保护状态在同一锁内完成，避免用旧状态解除刚生效的满速保护；降温恢复只写成功部分风扇时，也会重新确认保护状态。
- **自动重试与终端设定**：应用的自动恢复、启动清理和退出操作由后台服务检查当前控制权，不再清除后来设置的 CLI 转速。用户主动按“默认”或执行 `macfanpro auto` 仍可取消设定。
- **执行确认**：菜单栏应用与 `watch` 共用成功确认及失败重试逻辑，旧配置的迟到回调不会覆盖新选择；满速指令失败后，温度处于保护回差区间时仍会重试。
- **短间隔调速**：`watch --interval 0.01` 等短间隔可以累计升降速步长，不再因单步过小而停住。
- **逐风扇转速回报**：CLI 按各风扇自己的范围限速并显示对应目标，不再把第一只风扇的数值复制给所有风扇。

智能模式曲线、持续触发等待时间及 95°C 触发、低于 90°C 解除保护的阈值保持原有设置。

## 升级说明

本版增加后台服务的条件释放指令，**应用与后台服务必须一同更新**。先退出应用，升级后执行 `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install` 并重新打开应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。无需重新校准，原有数据和设置保留。
