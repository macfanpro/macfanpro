This release organizes the update banner into two labelled options and makes the from-source command complete, so you can copy and run it. Based on ThermalForge 0.2.3.

## What's changed

### Improved

- **Clear update options**: the banner now shows two options.
  - **Option 1 (recommended)**: the easiest way for how you installed, Homebrew or the release package. Click **Update in Terminal**, or copy the command shown.
  - **Option 2: Build from source**: for developers.
  - In Arabic, commands now stay left to right.
- **Complete from-source update command**: the "Built from source?" line in the update banner used to show only `git pull && ./setup.sh`, which works only after you `cd` into your source folder. It now shows a command you can run as is:
  - An app built with `setup.sh` remembers its source folder and shows `cd <folder> && git pull --ff-only && ./setup.sh`.
  - Apps from a release package or Homebrew show a command that clones the source into `~/macfanpro` if needed, then pulls and runs `setup.sh`.

Fan control, curves and protection thresholds are unchanged.

## 中文说明

本次更新把更新提示整理为两种标明的方式，并让源码更新命令完整、可直接复制执行。基于 ThermalForge 0.2.3。

### 更新内容

- **改进 清楚的更新方式**：更新提示分为两种方式。
  - **方式一（推荐）**：按你的安装方式（Homebrew 或发行包）最简单的更新方法，点“在终端中更新”，或复制显示的命令。
  - **方式二：从源码构建**：面向开发者。
  - 阿拉伯语界面中，命令保持从左到右显示。
- **改进 完整的源码更新命令**：更新提示中“从源码构建？”一行原来只显示 `git pull && ./setup.sh`，需要先进入源码目录才能执行。现在显示可直接执行的完整命令：
  - 用 `setup.sh` 构建的应用会记住源码目录，显示 `cd <目录> && git pull --ff-only && ./setup.sh`；
  - 通过发行包或 Homebrew 安装的应用，显示的命令会在需要时把源码克隆到 `~/macfanpro`，再拉取更新并运行 `setup.sh`。

风扇控制、温控曲线和保护阈值未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本) · [Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

### 升级说明

0.2.3.32 及以上版本直接点“有可用更新”提示里的“在终端中更新”。更早的版本运行上面的在线安装脚本，或沿用原安装方式更新。详见[更新步骤](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#更新)。
