本次更新修复 0.2.3.20 校准功能引入的安全问题，并补全复核发现的三处时序问题。基于 ThermalForge 0.2.3。**使用 0.2.3.20 的用户请尽快升级。**

## 更新内容

### 安全

- `sudo macfanpro calibrate` 现在以你自己的权限读写 `~/Library/Application Support/MacFanPro/` 中的校准文件。0.2.3.20 以 root 身份写入后再修改文件所有者：如果本机有程序以你的身份在该目录预先放置符号链接，再由你运行校准，root 会覆盖链接指向的系统文件，并把它交给你的账户。0.2.3.20 之前的版本把校准写在 root 目录，不受此问题影响。

### 修复

- **高温保护结束时**：在同一把锁内重新确认风扇设定；若 `auto` 已经取消了设定，不再恢复旧转速。
- **心跳看门狗**：在确认超时的同一步清除过期设定，复位期间到达的心跳不会再让记录保持“手动”，而风扇实际已回到自动。
- **默认按钮**：“默认”的结果晚于你后来选择的模式到达时，不再把模式改回 Silent；切换完成前，旧模式的任何指令（包括满速）都不会排在复位之后。

温控曲线和 95°C 安全阈值未改变。

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。本版修改了后台服务，Homebrew 更新后必须同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。

运行校准前，请先用 `macfanpro auto --stop-app` 退出菜单栏应用，完成后再打开。应用在 Smart 等模式下会同时调整风扇，干扰校准结果。
