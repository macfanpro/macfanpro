This release makes updating one click: an **Update in Terminal** button runs the right update steps for your install. Based on ThermalForge 0.2.3.

## What's changed

### New

- **Update in Terminal**: when a new version is out, the "Update available" banner has a button that opens Terminal and runs the update for how you installed MacFanPro. You enter your Mac password once.
  - Release-package install: downloads the new version, verifies its checksum and installs it.
  - Homebrew install: trusts the tap, upgrades, and syncs the background service.
  - Terminal tools don't follow the macOS proxy settings, so the update uses your system proxy when the shell has none. This helps on networks that need a proxy to reach GitHub.
  The command stays visible in the banner if you prefer to run it yourself.

### Improved

- **Automatic Homebrew releases**: after a release is published, the Homebrew tap updates its formula and prebuilt bottle and checks that it installs, with no manual steps.

Fan control, curves and protection thresholds are unchanged.

Homebrew 7 needs `brew trust macfanpro/tap` once.

## Upgrading

This version is the first with the button, so update to it the usual way:

- **Release package**: download the package above, extract it, quit the menu bar app, and in the extracted folder run `sudo ./bin/macfanpro install`, then `open /Applications/MacFanPro.app`.
- **Homebrew**: `brew trust macfanpro/tap && brew upgrade macfanpro`, then `macfanpro auto --stop-app` and `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install`.

From then on, use **Update in Terminal**. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## Verification and limits

- Automated: [Source CI](https://github.com/macfanpro/macfanpro/actions/runs/36613535045) and [Release CI](https://github.com/macfanpro/macfanpro/actions/runs/36613538929) passed (150 tests each in Debug and Release, plus packaging and localization checks).
- On hardware: M4 Max MacBook Pro, macOS 27.0, behind a system proxy. Both update scripts were run end to end: the release-package one picked up the system proxy, downloaded and verified a release and installed it; the Homebrew one upgraded and synced. The downloaded package was checked against SHA-256 and strict code signing, then installed; the binaries are byte-identical to the package.
- Signing and notarization: the package is ad-hoc signed and not yet notarized by Apple. Tested only on an M4 Max.
- Validation record (in Chinese): [0.2.3.32](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.32-validation.md)

## 中文说明

本次更新让更新只需一键：新增“在终端中更新”按钮，按你的安装方式自动执行更新步骤。基于 ThermalForge 0.2.3。

### 更新内容

- **在终端中更新**：有新版本时，“有可用更新”提示里多了一个按钮，点一下会打开终端，按你的安装方式完成更新，只需输入一次电脑密码。
  - 发行包安装：自动下载新版本、核对校验和并安装。
  - Homebrew 安装：自动信任软件源、升级并同步后台服务。
  - 终端里的工具不会跟随 macOS 的代理设置，所以更新时如果终端里没有设置代理，会自动使用系统代理。需要代理才能访问 GitHub 的网络也能正常更新。
  提示中仍会显示完整命令，你也可以自己复制执行。
- **Homebrew 发版自动化**：每次正式发布后，Homebrew 软件源会自动更新配方和预编译包，并确认可以正常安装，无需手动操作。

风扇控制、温控曲线和保护阈值未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

### 升级说明

这是第一个带有该按钮的版本，本次请按原来的方式更新：

- **发行包**：下载上方的发行包并解压，退出菜单栏应用，在解压出的文件夹中运行 `sudo ./bin/macfanpro install`，然后 `open /Applications/MacFanPro.app`。
- **Homebrew**：`brew trust macfanpro/tap && brew upgrade macfanpro`，然后 `macfanpro auto --stop-app` 和 `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install`。

之后的版本直接点“在终端中更新”即可。详见 [更新步骤](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#更新)。
