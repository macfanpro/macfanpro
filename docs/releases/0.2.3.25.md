本次更新在菜单中加入“检查更新”按钮，并让更新检查在通过代理访问 GitHub 时也能正常工作。基于 ThermalForge 0.2.3。

## 更新内容

### 新增

- **检查更新**：菜单底部“版本”下方新增“检查更新”按钮，可立即检查，不必等每天一次的自动检查。按钮左侧显示结果：正在检查、已是最新版本、有新版本或无法连接 GitHub。发现新版本时显示原有的更新提示和升级命令；即使之前点过“稍后”，手动检查也会显示，每天的自动检查仍然尊重“稍后”。

### 修复

- **经代理访问时更新检查失败**：更新检查改为访问公开的发布页（`/releases/latest` 会跳转到最新版本），不再调用 GitHub API。未登录的 GitHub API 每个 IP 每小时只允许 60 次请求，许多用户共用的代理出口 IP 经常已无剩余额度，导致检查一直失败。自动检查也使用新方式。检查使用系统代理设置。

风扇控制、温控曲线和保护阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.25-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.25/MacFanPro-0.2.3.25-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.25/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。
