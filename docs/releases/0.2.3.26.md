本次更新调整菜单底部“更新”一行的样式，使其与其他行一致。基于 ThermalForge 0.2.3。

## 更新内容

### 改进

- **“更新”一行**：改为与“语言”一行相同的布局和字号：左侧平时显示“更新”，检查后显示结果（已是最新版本、有新版本或无法连接 GitHub），右侧为常规尺寸的“检查”按钮。0.2.3.25 中这一行使用了较小的文字和按钮。

更新检查的方式、风扇控制与保护阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.26-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.26/MacFanPro-0.2.3.26-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.26/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。Homebrew 更新后仍需同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。

## 验证与限制

- 自动化验证：[源码 CI](https://github.com/macfanpro/macfanpro/actions/runs/36524309959) 与 [发行 CI](https://github.com/macfanpro/macfanpro/actions/runs/36524312580) 通过（Debug、Release 各 147 项测试，打包与语言资源检查）。
- 本机验证：M4 Max MacBook Pro、macOS 27.0。三种语言、四种状态的界面渲染核对；下载本版发行包核对 SHA-256 与严格签名后安装，应用与后台服务版本一致、二进制与发行包一致，实际按下“检查”显示正确结果。
- 签名与公证：发行包使用 ad-hoc 签名，尚未经过 Apple 公证。只在 M4 Max 上实测。
