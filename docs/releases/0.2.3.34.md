This release makes Homebrew updates through **Update in Terminal** run without stopping for input, and with far less unrelated output. Based on ThermalForge 0.2.3.

## What's changed

### Fixed

- **No hidden confirmation**: Homebrew 7 asks for `y/n` before upgrading. The prompt was buried in the update output, so Terminal could appear stuck. Clicking **Update in Terminal**, or running the online installer, now counts as the confirmation.
- **No misleading warning**: `macfanpro auto --stop-app` runs right before the background service is reinstalled. At that point a newer CLI talking to the older service is expected, so it no longer prints the "Version mismatch" warning. Other commands still warn.

### Improved

- **Faster, quieter Homebrew updates**: the updater refreshes only the MacFanPro tap instead of running `brew update`. `brew update` fetched every tap, printed errors from unrelated taps or mirrors, and does nothing for people who set `HOMEBREW_NO_AUTO_UPDATE`. If the tap can't be refreshed, `brew update` is still used.
- **Faster Homebrew releases**: publishing a release immediately starts the Homebrew tap update, so the new version reaches Homebrew in a few minutes instead of up to an hour.

Fan control, curves and protection thresholds are unchanged.

## Upgrading

On 0.2.3.32 or 0.2.3.33, click **Update in Terminal** in the "Update available" banner. The update to this version still runs the old updater, so on Homebrew you may be asked to press `y` one last time. On earlier versions, run the online installer above, or update the way you installed. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## 中文说明

本次更新让通过 Homebrew 的“在终端中更新”全程无需额外操作，无关输出也少得多。基于 ThermalForge 0.2.3。

### 更新内容

- **修复 隐藏的确认提示**：Homebrew 7 升级前会要求按 `y/n` 确认。这个提示夹在更新输出中间，终端看起来像卡住了。现在点“在终端中更新”或运行在线安装脚本，就视为已经确认。
- **修复 误导性的版本不一致警告**：`macfanpro auto --stop-app` 在重装后台服务前执行，此时新命令行对着旧后台服务是正常的，不再显示“Version mismatch”警告；其他命令照常提醒。
- **改进 更新更快、输出更少**：更新时只刷新 MacFanPro 的软件源，不再执行 `brew update`。`brew update` 会刷新所有软件源，会显示其他软件源或镜像的错误，而且设置了 `HOMEBREW_NO_AUTO_UPDATE` 时根本不会执行。刷新失败时仍会改用 `brew update`。
- **改进 Homebrew 更快拿到新版**：正式发布后立即启动 Homebrew 软件源更新，几分钟内即可升级，不再最多等一小时。

风扇控制、温控曲线和保护阈值未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本) · [Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

### 升级说明

0.2.3.32 或 0.2.3.33 用户直接点“有可用更新”提示里的“在终端中更新”。这次升级执行的仍是旧版的更新脚本，Homebrew 用户可能还需要最后按一次 `y`。更早的版本运行上面的在线安装脚本，或沿用原安装方式更新。详见[更新步骤](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#更新)。
