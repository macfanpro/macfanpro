This release makes the background service's diagnostics readable in the system log, and confirms on real hardware the fan release added in 0.2.3.55. Based on ThermalForge 0.2.3.

## What's changed

- **Readable service diagnostics:** since the macOS 26 SDK, everything the background service wrote with `NSLog` appeared in the system log as `<private>`. The service now uses ThermalForge's `DaemonLog` channel (#31), so these messages are readable: starting, fan release at start and stop, the thermal floor, sleep/wake, and each request's outcome. Read them with:
  ```bash
  log show --last 1h --style compact --predicate 'subsystem == "io.github.macfanpro.daemon"'
  ```
- The bounded runtime log files, fan control, curves and protection thresholds are unchanged.
