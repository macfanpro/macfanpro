This release makes updates easier to find and improves installation failure recovery. Based on ThermalForge 0.2.3.

## What's changed

- **Separate update window:** new releases appear in a compact Updates row. Open details for release notes and the appropriate Homebrew or app-download action. Other commands and proxy help remain available without covering fan readings. All 18 languages are supported.
- **Clear update handoff:** opening Terminal reports failures, allows retry, and prevents duplicate launches while an update is being handed off.
- **Safer installation:** incorporate upstream app/CLI build matching, complete app staging and atomic replacement, plus launchd state checks and startup retry.
- **Staging-directory safety:** keep C buffer access within its valid lifetime and verify the private directory before preparing or cleaning an app. This fixes a Release-optimization failure caught by CI before publication.
- **Failure recovery:** restore previous service files if installation fails after stopping the service. Uninstall stops on service-shutdown or fan-reset failure; failed launchd queries are no longer mistaken for an absent service.

Fan curves, safety thresholds, disconnect protection and logging are unchanged. Existing Homebrew, online, proxy and source installation remain available.

## Verification and limits

Release verification is recorded in the [version-specific validation record](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.52-validation.md). Automated tests and package checks are separate from real administrator installation and hardware testing.

- [Main CI](https://github.com/macfanpro/macfanpro/actions/runs/37583164162) and [Release CI](https://github.com/macfanpro/macfanpro/actions/runs/37583175333) passed: 155 tests in each configuration, disconnect regressions, 17 installer checks and resource packaging.
- All six draft assets were downloaded and verified, including checksums, signatures, versions, 18 catalogs and DMG/tar equality. App replacement and failure-preservation checks also passed using the downloaded release binaries. Candidate 0.2.3.51 failed CI and was not published; this version includes the correction.
- After publication, the public online installer passed `--check`; the [Homebrew workflow](https://github.com/macfanpro/homebrew-tap/actions/runs/37583839533) published and installed the prebuilt bottle, passed `brew test`, and updated the formula.

Packages use **ad-hoc signing and are not notarized by Apple**. Real administrator authorization, clean-Mac installation, privileged service upgrade/removal and thermal/sleep-wake acceptance are not covered by this release's automated checks.

## 中文说明

本版优化更新入口，并增强安装失败时的恢复能力。基于 ThermalForge 0.2.3。

### 更新内容

- **独立更新窗口**：新版本显示在菜单底部的“更新”行，点击查看更新说明及对应安装渠道的操作。其他更新命令和代理帮助按需展开，不再遮挡风扇读数，支持全部 18 种语言。
- **更新启动反馈**：终端启动失败会显示提示并支持重试，启动过程中避免重复打开。
- **安装可靠性**：整合上游应用与 CLI 构建校验、完整应用预备和原子替换、launchd 状态检查与启动重试。
- **暂存目录保护**：在有效生命周期内读取 C 缓冲区，准备或清理应用前校验私有目录。修复 CI 在公开发布前发现的 Release 优化问题。
- **失败恢复**：停止服务后的安装步骤失败会恢复原有后台文件；卸载在服务停止或风扇重置失败时结束；服务状态查询失败不会再被当成服务不存在。

风扇曲线、安全阈值、断连保护和日志行为保持不变。Homebrew、在线脚本、代理和源码安装继续支持。

### 下载与升级

要求 **配备实体风扇的 Apple Silicon Mac、macOS 14 或更高版本**，附件见上表及[安装教程](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#安装)。

Homebrew 用户继续使用 Homebrew。DMG 用户退出应用后，将新版拖入“应用程序”替换并重新打开，按提示授权同步后台服务。**升级无需先卸载后台服务。** 国内无法正常访问 GitHub 时，请按[代理教程](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本)操作。

### 验证与限制

验证结果见[本版本记录](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.52-validation.md)，区分自动化测试、发行附件检查与实机验收。

- 已下载全部 6 个草稿附件，核对校验和、签名、版本、18 种语言和 DMG/tar 一致性，并用实际下载的二进制通过应用替换与失败保护检查。0.2.3.51 候选在 CI 失败后未公开，本版包含对应修复。

继续采用 **ad-hoc 签名，未经 Apple 公证**。自动化检查不包含真实管理员授权、干净 Mac 首次安装、特权服务升级/卸载和温控、睡眠唤醒实机验收。
