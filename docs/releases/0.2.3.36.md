This release gives MacFanPro a new app icon in a tech palette. Based on ThermalForge 0.2.3.

## What's changed

### Improved

- **New app icon**: the fan now has a cyan to violet gradient and a soft glow, on a deep navy tile with a thin cyan edge. The edge is left out at the smallest sizes to keep them legible. The new icon shows in the Dock, Finder and Launchpad.
- The social preview images for the repository use the same style, in English and Chinese.

Menu bar and panel colors, fan control, curves and protection thresholds are unchanged.

## Upgrading

On 0.2.3.32 or later, click **Update in Terminal** in the "Update available" banner. On earlier versions, run the online installer above, or update the way you installed. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## Verification and limits

- Automated: [Source CI](https://github.com/macfanpro/macfanpro/actions/runs/36691755550) and [Release CI](https://github.com/macfanpro/macfanpro/actions/runs/36691755514) passed: 150 Swift tests each in Debug and Release, 16 installer integration tests, and packaging, localization and installer checks.
- Release assets: The draft assets passed both checksum files. The CLI reports 0.2.3.36, the app passes strict code signing, and the binaries target macOS 14. The icon inside the app matches the new `MacFanPro.icns` in the repository, and the `install.sh` asset is byte-identical to the copy inside the app.
- On hardware: M4 Max MacBook Pro, macOS 27.0. Clicking **Update in Terminal** on 0.2.3.35 upgraded Homebrew to 0.2.3.36 from the prebuilt bottle and finished about 24 seconds after the click, including the password prompt. The app, CLI and background service are 0.2.3.36 and byte-identical to the Homebrew keg, with no version mismatch. The installed app carries the new icon. New English and Chinese panel screenshots were taken from this build for the README and social previews.
- Signing and notarization: the package is ad-hoc signed and not notarized by Apple. Tested only on an M4 Max.

## 中文说明

本次更新为 MacFanPro 换上科技配色的新应用图标。基于 ThermalForge 0.2.3。

### 更新内容

- **改进 新应用图标**：风扇改为青→蓝→紫渐变，带柔和光晕，底板为深海军蓝，外加一圈细的青色边框。为保证清晰，最小尺寸不画边框。新图标显示在程序坞、访达和启动台中。
- 仓库的中、英文社交预览图也换成同一风格。

菜单栏和面板颜色、风扇控制、温控曲线和保护阈值均未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本) · [Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。
