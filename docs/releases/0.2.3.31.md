This release fixes the upgrade steps in the "Update available" banner, which were wrong for release-package installs. Based on ThermalForge 0.2.3.

## What's changed

### Fixed

- **Update steps that match how you installed**: the banner used to show a Homebrew command to everyone, so people who installed the release package and followed it got Homebrew errors. It now shows:
  - for a release-package install: download the new version, then run `sudo ./bin/macfanpro install` in its folder (with a Download link);
  - for a Homebrew install: `brew trust macfanpro/tap && brew upgrade macfanpro && sudo macfanpro install`, including the `brew trust` step Homebrew 7 requires.

Fan control, curves and protection thresholds are unchanged.

## Download and install

Requires **an Apple Silicon Mac with macOS 14 or later**.

Choose one install method: [Homebrew](https://github.com/macfanpro/macfanpro#option-1-homebrew) (prebuilt, no Xcode needed) · [Release download](https://github.com/macfanpro/macfanpro#option-2-release-download) · [From source](https://github.com/macfanpro/macfanpro#option-3-from-source). Homebrew 7 needs `brew trust macfanpro/tap` once.

## Upgrading

- **Release package**: download the package above, extract it, quit the menu bar app, and in the extracted folder run `sudo ./bin/macfanpro install`, then `open /Applications/MacFanPro.app`.
- **Homebrew**: `brew trust macfanpro/tap && brew upgrade macfanpro`, then `macfanpro auto --stop-app` and `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install`. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## Verification and limits

- Automated: [Source CI](https://github.com/macfanpro/macfanpro/actions/runs/36610462956) and [Release CI](https://github.com/macfanpro/macfanpro/actions/runs/36610465996) passed (147 tests each in Debug and Release, plus packaging and localization checks).
- On hardware: M4 Max MacBook Pro, macOS 27.0. The downloaded package was checked against SHA-256 and strict code signing, then installed; the binaries are byte-identical to the package. In the installed app, a simulated newer version showed the banner with the Homebrew command; with the Homebrew keg hidden, it showed the release-package steps instead.
- Signing and notarization: the package is ad-hoc signed and not yet notarized by Apple. Tested only on an M4 Max.
- Validation record (in Chinese): [0.2.3.31](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.31-validation.md)

## 中文说明

本次更新修正“有可用更新”提示中的升级步骤：此前对发行包用户给出的命令是错的。基于 ThermalForge 0.2.3。

### 更新内容

- **按安装方式给出更新步骤**：提示以前对所有人都显示 Homebrew 命令，用发行包安装的用户照做会遇到 Homebrew 报错。现在：
  - 发行包安装：提示下载新版本，然后在其文件夹中运行 `sudo ./bin/macfanpro install`，并提供“下载”链接；
  - Homebrew 安装：显示 `brew trust macfanpro/tap && brew upgrade macfanpro && sudo macfanpro install`，补上了 Homebrew 7 要求的 `brew trust`。

风扇控制、温控曲线和保护阈值未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

### 升级说明

- **发行包**：下载上方的发行包并解压，退出菜单栏应用，在解压出的文件夹中运行 `sudo ./bin/macfanpro install`，然后 `open /Applications/MacFanPro.app`。
- **Homebrew**：`brew trust macfanpro/tap && brew upgrade macfanpro`，然后 `macfanpro auto --stop-app` 和 `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install`。详见 [更新步骤](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#更新)。

### 验证与限制

- 自动化验证：[源码 CI](https://github.com/macfanpro/macfanpro/actions/runs/36610462956) 与 [发行 CI](https://github.com/macfanpro/macfanpro/actions/runs/36610465996) 通过（Debug、Release 各 147 项测试，打包与语言资源检查）。
- 本机验证：M4 Max MacBook Pro、macOS 27.0。下载本版发行包核对 SHA-256 与严格签名后安装，二进制与发行包一致。在已安装的应用中模拟有新版本：显示 Homebrew 命令；临时隐藏 Homebrew keg 后，改为显示发行包的更新步骤。
- 签名与公证：发行包使用 ad-hoc 签名，尚未经过 Apple 公证。只在 M4 Max 上实测。
- 验证记录：[0.2.3.31 验证记录](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.31-validation.md)
