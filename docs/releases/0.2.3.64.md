MacFanPro is now **MacFanControl**. This is a compatibility transition release, based on ThermalForge 0.2.3. The repository and website remain at their existing addresses.

## What's changed

- New display name throughout the app and website, in all 18 languages.
- Update checks recognize both the current repository and the future `macfancontrol/macfancontrol` address. Please update before the later repository move.
- App files, command, packages and source modules use MacFanControl. Compatibility aliases let older update scripts upgrade the app while preserving existing settings.
- The website language selector arrow is vertically centered.

## Download and update

**[Download MacFanControl 0.2.3.64 for macOS (DMG)](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.64/MacFanControl-0.2.3.64-macos-arm64.dmg)**

Requires macOS 14+ and an Apple Silicon Mac with physical fans. Quit the old app, drag `MacFanControl.app` into Applications and replace it, then reopen and authorize service synchronization if requested. The installed app is MacFanControl.app. Homebrew users should continue using Homebrew. Settings are preserved.

[Other installation methods and proxy help](https://github.com/macfanpro/macfanpro#install) · [Transition details](https://github.com/macfanpro/macfanpro/blob/main/docs/macfancontrol-transition.md)

Packages use ad-hoc signing and are not notarized by Apple. This release does not migrate the repository; GitHub remains primary and Gitee remains a mirror.
