MacFanControl now lives at **macfancontrol/macfancontrol**, with a new website and retained upgrade support for MacFanPro. Based on ThermalForge 0.2.3.

## Changes

- New official repository: https://github.com/macfancontrol/macfancontrol
- New 18-language website: https://macfancontrol.github.io/macfancontrol/
- Existing update clients continue using the old repository's verified compatibility releases. The old website redirects to the new site, preserving language and page location.
- Update checks, online installation and source-build links use the new repository. Homebrew and Gitee automation follow the new authoritative source.
- Existing settings, daemon identity and old command/package aliases are retained. Fan-control behavior is unchanged.

## Download and upgrade

**[Download MacFanControl 0.2.3.65 for macOS (DMG)](https://github.com/macfancontrol/macfancontrol/releases/download/v0.2.3.65/MacFanControl-0.2.3.65-macos-arm64.dmg)**

For Apple Silicon Macs with physical fans, macOS 14 or later. Quit the old app, drag MacFanControl.app into Applications, reopen it and authorize service synchronization if requested. Homebrew users should continue using Homebrew. Existing users can keep their usual update entry point.

[Installation and proxy help](https://github.com/macfancontrol/macfancontrol#install) · [Migration details](https://github.com/macfancontrol/macfancontrol/blob/main/docs/macfancontrol-transition.md)

Source developers should update their clone: `git remote set-url origin https://github.com/macfancontrol/macfancontrol.git`.

Packages remain ad-hoc signed, not Apple-notarized. Automated and downloaded-package validation is documented in the [validation record](https://github.com/macfancontrol/macfancontrol/blob/main/docs/macfancontrol-0.2.3.65-validation.md). No privileged install or fan-control test was performed on the maintainer's Mac for this release.
