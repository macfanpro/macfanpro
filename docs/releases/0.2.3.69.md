[中文说明](#中文说明)

Reduce redundant interface updates and routine logging overhead. Based on ThermalForge 0.2.3.

## Changes

- Notify the interface only when monitor or daemon state changes. Sensor readings and genuine profile, safety and connectivity changes still update normally.
- Stop logging successful routine status/heartbeat queries. Sample ordinary supervised speed-request and per-fan target diagnostics every 30 seconds per key.
- Preserve failed requests, advisory results, explicit CLI commands, ownership changes, and existing safety/recovery diagnostics. Fan control and safety behavior are unchanged.
- Selectively adapt upstream PR #52 performance fixes; no custom-curve editor, status-item replacement or persistent log handles are introduced.

## Download and install

Apple Silicon Macs with physical fans, macOS 14 or later.

## Verification and limitations

Local and hosted macOS 15 CI/Release checks passed: Debug and Release each ran 187 tests, together with disconnect, installer, mirror and localization-packaging checks. All six official draft assets were built by the hosted workflow, downloaded anew and verified before publication (checksums, signatures, versions, language resources and old-updater compatibility).

See the [version validation record](https://github.com/macfanpro/macfanpro/blob/df21a3aad18acb09214240668037543dd4238f9a/docs/macfanpro-0.2.3.69-validation.md). Packages use ad-hoc signatures and are not notarized by Apple. No physical fan-control, high-temperature, or physical sleep/wake acceptance is performed for this optimization; no claim of measured battery or whole-app CPU improvement is made.

减少重复界面通知和常规日志开销。基于 ThermalForge 0.2.3。

### 更新内容

- 仅在监控或后台服务状态变化时通知界面；传感器读数以及实际模式、安全和连接状态变化仍正常更新。
- 成功的常规状态及心跳查询不再逐条记日志；普通应用转速请求和每个风扇的目标转速诊断按键每 30 秒采样一次。

- 选择性吸收上游 PR #52 的性能修复，没有引入自定义曲线编辑器、菜单栏架构替换或长期复用的日志文件句柄。
