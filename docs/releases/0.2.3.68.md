[中文说明](#中文说明)

Check for new releases every six hours instead of every 24 hours. Based on ThermalForge 0.2.3.

## Changes

- Shorten automatic update checks to six hours. Failed checks still retry after about one hour, and manual checks remain available.
- Keep the previously scheduled check when upgrading; the six-hour interval applies after the next successful automatic or manual check. Sleeping Macs check when the app resumes and the scheduled time has arrived.

## Download and install

Apple Silicon Macs with physical fans, macOS 14 or later.

- [DMG](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.68/MacFanPro-0.2.3.68-macos-arm64.dmg) · [DMG SHA-256](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.68/MacFanPro-0.2.3.68-macos-arm64.dmg.sha256)
- [App + CLI archive](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.68/MacFanPro-0.2.3.68-macos-arm64.tar.gz) · [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.68/SHA256SUMS)
- [Installation, Homebrew and proxy instructions](https://github.com/macfanpro/macfanpro/blob/main/README.md#install)

Quit the old app before replacing it; reopen and authorize service synchronization if requested. Homebrew users should continue using Homebrew. Settings and calibration are retained.

## Verification and limitations

Local Debug and Release tests passed (182 tests each), together with installer, disconnect, mirror and localization-packaging checks. Downloaded-draft verification is pending; the release will remain a draft until acceptance is complete.

See the [version validation record](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.68-validation.md). Packages use ad-hoc signatures and are not notarized by Apple. No physical fan-control, high-temperature, or sleep/wake acceptance was performed for this update-check scheduling change.

### 更新内容

- 每 6 小时自动检查一次更新，失败后仍约 1 小时重试；随时可以手动检查。
- 升级时保留之前已安排的下一次检查时间，下一次自动或手动检查成功后采用 6 小时间隔。电脑休眠期间不会专门唤醒检查，应用恢复运行且到期后再检查。
