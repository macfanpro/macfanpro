> **安全提示：** 本版的校准写入存在符号链接覆盖问题，请升级到 [0.2.3.21](https://github.com/macfanpro/macfanpro/releases/tag/v0.2.3.21)。

本次更新修复几种会让风扇实际状态与菜单显示不一致的情况，并修复 Smart 模式读不到校准结果的问题。基于 ThermalForge 0.2.3。

## 更新内容

### 修复

- **默认按钮**：风扇正在变速时按“默认”，旧模式的转速指令可能在恢复自动之后才写入，导致菜单显示 Silent，风扇却仍处于手动转速。现在恢复自动总是最后一次写入。
- **睡眠唤醒**：唤醒后，后台服务会在 2 秒后重新写入睡眠前的风扇设定。如果这段时间内设定已被释放或替换，或者高温保护正在让风扇满速运行，现在不再重新写入过时的转速。
- **看门狗与高温保护**：看门狗复位风扇前会再确认一次心跳确实已超时；高温保护结束时恢复写入失败的，会继续重试，不再显示“保护已结束”而实际仍满速。
- **校准**：`sudo macfanpro calibrate` 现在把结果存到你自己的 `~/Library/Application Support/MacFanPro/`，而不是 root 的目录，Smart 模式才能真正用上校准数据。过热判断同时看 CPU 和 GPU 温度，与 Smart 查表使用的温度一致。

以上问题均继承自上游，修改只在原位置增加检查，温控曲线和 95°C 安全阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.20-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.20/MacFanPro-0.2.3.20-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。本版修改了后台服务，Homebrew 更新后必须同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。

以前运行过的校准结果存在 root 的目录中，应用从未读取过。如需使用校准，请升级后重新运行 `sudo macfanpro calibrate`。
