This release adds a one-command online installer, and **Update in Terminal** now uses it, so installs and updates get the same checks. Based on ThermalForge 0.2.3.

## What's changed

### New

- **Online installer**: install or update with one command:
  ```bash
  curl -fsSL https://github.com/macfanpro/macfanpro/releases/latest/download/install.sh | bash
  ```
  - Run it as your normal user. It downloads the release package and checks it before installing: the checksum, the archive contents, the app's identity and version, and its code signature.
  - It asks for your Mac password once, installs, and confirms that the background service is running.
  - If you installed with Homebrew, it updates through Homebrew instead.
  - It never downgrades, and keeps your configuration and calibration.
  - `--check` only downloads and verifies, without installing. See [Online installer](https://github.com/macfanpro/macfanpro#online-installer).

### Improved

- **Update in Terminal** runs the same installer, which is bundled inside the app. For Homebrew installs it trusts the tap, and continues if `brew update` fails for another tap.
- `sudo macfanpro install` now asks the running background service which version it is. It fails if that is not the version just installed, instead of reporting success for an old service.
- The "Built from source?" hint in the update banner shows `git pull && ./setup.sh` as a separate command you can select and copy.

Fan control, curves and protection thresholds are unchanged.

## Upgrading

On 0.2.3.32, click **Update in Terminal** in the "Update available" banner. On earlier versions, run the online installer above, or update the way you installed. See [Updating](https://github.com/macfanpro/macfanpro#updating).

## Verification and limits

- Automated: [Source CI](https://github.com/macfanpro/macfanpro/actions/runs/36661900614) and [Release CI](https://github.com/macfanpro/macfanpro/actions/runs/36661900699) passed: 149 Swift tests each in Debug and Release, 16 installer integration tests, and packaging, localization and installer checks.
- Release assets: The draft assets passed both checksum files. The CLI reports 0.2.3.33, the app passes strict code signing, and the binaries target macOS 14. The `install.sh` asset is byte-identical to the copy inside the app and defaults to 0.2.3.33. After publishing, that asset was run with `curl … | bash -s -- --check`: it downloaded and verified this release without installing. `SHA256SUMS` lists only the package, so the 0.2.3.32 **Update in Terminal** button works with this release.
- Not yet run on hardware: a real privileged install through the new installer. Updating from this version with its **Update in Terminal** button can only be tested once a newer release exists. This release adds no fan-control changes and no new hardware testing.
- Signing and notarization: the package is ad-hoc signed and not notarized by Apple. The checksums show that the download is intact. They come from the same GitHub release, so they cannot show that the repository itself is uncompromised. Tested only on an M4 Max.

## 中文说明

本次更新新增一条命令的在线安装脚本，“在终端中更新”也改用这个脚本，安装和更新执行同样的检查。基于 ThermalForge 0.2.3。

### 更新内容

- **新增 在线安装脚本**：一条命令即可安装或更新：
  ```bash
  curl -fsSL https://github.com/macfanpro/macfanpro/releases/latest/download/install.sh | bash
  ```
  - 用普通用户身份运行。脚本下载发行包，安装前先检查：校验和、压缩包内容、应用身份和版本、代码签名。
  - 只需输入一次电脑密码，安装后确认后台服务已在运行。
  - 通过 Homebrew 安装的，改由 Homebrew 更新。
  - 不会降级，保留配置和校准数据。
  - `--check` 只下载和校验，不安装。详见[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本)。
- **改进 在终端中更新**：改用应用内附带的同一份安装脚本。Homebrew 安装会先信任软件源；某个 tap 导致 `brew update` 失败时继续更新。
- **改进 安装确认**：`sudo macfanpro install` 会向正在运行的后台服务确认版本号；不是刚安装的版本时报错，不再对旧服务报告安装成功。
- **改进 源码构建提示**：更新提示中的“从源码构建？”一行，把 `git pull && ./setup.sh` 单独显示成可选中复制的命令。

风扇控制、温控曲线和保护阈值未改变。

### 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。下载文件见上方表格。

选择一种安装方式：[在线安装脚本](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#在线安装脚本) · [Homebrew](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式一通过-homebrew-安装)（预编译，无需 Xcode） · [下载发行包](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。
