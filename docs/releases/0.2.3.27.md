本次更新把菜单底部的按钮名称改为“检查更新”。基于 ThermalForge 0.2.3。

## 更新内容

### 改进

- **按钮名称**：三种语言的按钮都改为“检查更新”（繁体“檢查更新”，英文 “Check for Updates”）。为了与英文按钮同行显示，英文结果文字改为 “New: {版本}” 和 “Can't connect”；中文结果不变。空间不足时只截断左侧文字，按钮始终完整显示。

更新检查的方式、风扇控制与保护阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.27-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.27/MacFanPro-0.2.3.27-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.27/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。Homebrew 更新后仍需同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。
