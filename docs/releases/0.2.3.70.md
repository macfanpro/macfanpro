[中文说明](#中文说明)

Keep explicit terminal speed changes diagnosable while routine ramp logs are rate-limited. Based on ThermalForge 0.2.3.

## Changes

- Record requested RPM, the requested fan for single-fan commands, accepted per-fan targets and advisory notes for successful explicit CLI speed commands. These records bypass ordinary ramp-log sampling.
- Label thermally queued targets as accepted targets and retain the safety advisory; do not imply the hardware has already adopted them.
- Add regression tests for repeated CLI speed changes, per-fan clamping, thermal queuing, temperature-only and mode-only updates, and disappearing sensors clearing stale display values.
- Fan-control execution, authorization, ownership and safety behavior are unchanged.

Apple Silicon Macs with physical fans, macOS 14 or later.

## Verification and limitations

Local Debug and Release each passed 190 tests, together with disconnect, installer, mirror and localization-packaging checks. Downloaded draft verification is pending.

See the [version validation record](https://github.com/macfanpro/macfanpro/blob/main/docs/macfanpro-0.2.3.70-validation.md). Packages use ad-hoc signatures and are not notarized by Apple. Tests use simulated SMC and isolated temporary resources; no real fan-control, high-temperature or physical sleep/wake acceptance is performed.

## 中文说明

修复常规转速日志限频期间，明确的终端调速命令可能缺少目标转速记录的问题。基于 ThermalForge 0.2.3。

### 更新内容

- 成功的明确终端调速命令记录请求转速、单风扇指令的风扇编号、各风扇接受的目标转速及提示信息，不受普通调速日志采样影响。
- 高温保护期间排队的目标明确标为“已接受目标”，保留安全提示，避免误称硬件已经切换到该转速。
- 增加连续终端调速、逐风扇限幅、高温保护排队，以及仅温度变化、仅风扇模式变化和传感器消失时清除旧读数的回归测试。
- 风扇控制执行、权限、控制权仲裁及安全机制保持原样。
