This release merges the update window into Settings, so MacFanPro has a single window. Based on ThermalForge 0.2.3.

## What's changed

- Update details now live in the **Updates** section of the settings window, which moves to the bottom: General, Background service, Updates. When a release is available, the section shows the new version, a **What's new** link and the update action (**Update in Terminal** for Homebrew, **Open download page** otherwise); installer and source commands and network help stay collapsed under **Other update methods** and **Download help**. The panel's "{version} available" row now opens Settings. The separate update window is gone.
- Settings taller than the screen, for example with **Other update methods** expanded, scroll inside the window instead of growing past the screen.
- The Homebrew update text now says administrator authorization **is** required rather than **may be**, since the update always restarts the background service.

Fan control, curves and protection thresholds are unchanged.

## 中文说明

本版把更新窗口并入设置窗口，MacFanPro 只剩一个窗口。

### 更新内容

- 更新详情移入设置窗口的“更新”分组，并把该分组移到最下方：通用 → 服务 → 更新。有新版本时，分组中显示新版本号、“更新内容”链接和更新按钮（Homebrew 为“在终端中更新”，其他安装方式为“前往下载”）；安装与源码命令、网络帮助仍收在“其他更新方式”和“下载遇到问题？”中。面板上“有新版本”一行改为打开设置窗口，独立的更新窗口已移除。
- 设置内容超过屏幕高度时（例如展开“其他更新方式”），在窗口内滚动，窗口不会超出屏幕。
- Homebrew 更新说明由“可能需要管理员授权”改为“需要管理员授权”，因为更新总会重启后台服务。

风扇控制、温控曲线和保护阈值均未改变。

### 下载与升级

要求 **配备实体风扇的 Apple Silicon Mac、macOS 14 或更高版本**，下载见上表。

Homebrew 用户继续使用 Homebrew；DMG 用户退出应用，将新版拖入“应用程序”替换后重新打开，按提示同步后台服务，升级无需先卸载服务。在线脚本、代理及源码安装继续保留，见[安装教程](https://github.com/macfanpro/macfanpro/blob/main/README.zh-CN.md#安装)。
