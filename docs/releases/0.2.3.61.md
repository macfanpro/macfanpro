This release gives all four buttons in the panel the same icon treatment. Based on ThermalForge 0.2.3.

## What's changed

- The **Smart** and **Default** buttons now handle their icons like **Quit** and **Settings**: the symbol is one size smaller, matches the text height, and sits centered on the text with 4 points of spacing.

Fan control, curves and protection thresholds are unchanged.
