本次更新修复第三轮审计确认的风扇状态、失败恢复、校准和安装问题。基于 ThermalForge 0.2.3。

## 更新内容

### 修复

- **写入失败后的恢复**：接管风扇手动控制时若中途失败，后台服务会把风扇交还自动控制；SMC 暂时不可用（例如半唤醒时）则每 5 秒重试，不再留下手动状态或被压制的系统温控。
- **高温保护**：设满转速与标记“保护中”在同一步完成，期间到达的指令不能再把风扇调低；降温恢复期间，看门狗不再清除正在恢复的设定。
- **95°C 保护的回差**：保护状态会保持到温度低于 90°C。此前 Silent 在 94°C 就交还了控制。
- **切换到 Silent / 默认**：不再丢弃 Silent 自己的第一次高温保护指令（0.2.3.21 引入的问题）。
- **Smart 和曲线模式降温后**：交还自动控制失败时会自动重试，不再停留在手动转速。
- **校准**：`sudo macfanpro calibrate` 运行期间会退出菜单栏应用，结束后重新打开，避免应用改写正在测量的风扇档位；未通过校验的结果不再保存，原有校准保留，文件以原子方式写入。
- **全部风扇设为同一转速**：按每个风扇各自的范围限制。
- **安装同步**：`brew upgrade` 后，从已安装的 CLI 执行 `sudo macfanpro install` 会找到较新的 Homebrew 应用包并同步，不再报 “No matching MacFanPro.app”。从本版起的后续升级生效。
- **`macfanpro watch --interval`**：升降速和持续触发时间按所选间隔计算，并拒绝非正数间隔。

温控曲线和 95°C 安全阈值未改变。

## 下载与安装

要求 **Apple Silicon Mac、macOS 14 或更高版本**。

| 文件 | 用途 |
| --- | --- |
| [MacFanPro-0.2.3.22-macos-arm64.tar.gz](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.22/MacFanPro-0.2.3.22-macos-arm64.tar.gz) | 完整应用与 CLI，解压后安装，无需 Xcode |
| [SHA256SUMS](https://github.com/macfanpro/macfanpro/releases/download/v0.2.3.22/SHA256SUMS) | 下载完整性校验 |

选择一种安装方式：[Homebrew](https://github.com/macfanpro/macfanpro#方式一通过-homebrew-安装) · [下载发行包](https://github.com/macfanpro/macfanpro#方式二下载发行包安装) · [源码构建](https://github.com/macfanpro/macfanpro#方式三从源码构建安装)。Homebrew 7 需要先执行一次 `brew trust macfanpro/tap`。

## 升级说明

更新前先退出菜单栏应用，再安装新版本并重新打开。本版修改了后台服务，Homebrew 更新后必须同步后台服务和应用，详见 [更新步骤](https://github.com/macfanpro/macfanpro#更新)。本次仍请使用 `sudo "$(brew --prefix macfanpro)/bin/macfanpro" install`；已安装 CLI 的自动同步从下一次升级起生效。
