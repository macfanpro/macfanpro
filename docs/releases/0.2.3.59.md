This release polishes the bottom row of the menu bar panel. Based on ThermalForge 0.2.3.

## What's changed

- **Quit** is now a button like **Settings**, with an exit icon (⌘Q), so the two actions read as a pair.
- The **Settings** button no longer ends in "…". Its gear icon already marks it.
- The bottom row has more space above it.

Fan control, curves and protection thresholds are unchanged.
