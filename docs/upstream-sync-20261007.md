## 采用与取舍

| 范围 | 本次处理 | 原因 |
| --- | --- | --- |
| launchd 停止与启动 | 引入状态轮询、停止超时、启动失败重试及原始错误信息 | 避免固定等待 0.5/1 秒导致慢机器或系统繁忙时误报失败。继续检查服务实际返回的版本，不能只检查 socket 可连接。 |
| 执行文件定位 | 引入 `_NSGetExecutablePath` 与 `realpath` | 避免安装来源依赖 `argv[0]`；同时用于 DMG 内嵌安装和卸载的路径校验。 |
| 应用来源 | 在本项目现有完整包选择上加入构建一致性检查 | 校验产品标识、版本及内嵌 CLI 的构建身份。签名和 Homebrew 去除符号会改变文件字节，因此允许 Mach-O CPU 类型与构建 UUID 一致的副本，并单独验证包签名。UUID 只用于构建一致性，不作为发布者身份认证。 |
| 完整应用替换 | 采用准备后原子交换，供 `build-app` 与命令行安装共用 | 准备失败保留旧应用。使用同卷随机、0700 暂存目录，避免固定暂存名；复制后的包在交换前再验证、清理属性，并交给安装用户所有。 |
| 常规文件复制 | 引入通过同一文件描述符校验和复制的方式 | 拒绝符号链接、FIFO、目录和已存在的输出；安装后台程序始终由 root 创建，并明确设为 0755，不继承来源所有者或 setuid/setgid。 |
| 外部命令与退出提示 | 引入输出捕获、实际进程状态确认 | 不以 killall/pkill 的返回码推断应用已退出；工具无法启动时也给出错误。无法停止应用时，卸载停止执行。 |
| 应用组装 | 保留 MacFanPro 的完整组装内容，应用原子交换机制 | 保留内嵌服务工具、18 种语言、在线安装脚本、源码目录信息、许可证及第三方声明；不采用上游仅组装应用二进制和图标的布局。 |
| 属性清理 | 保留 `find` + `xattr -cs`，增加错误输出捕获 | 上游新安装代码仍有 `xattr -cr` 路径；本项目保留不跟随包内链接去修改外部目标的实现。 |
| 风扇控制 | 保留本项目实现 | 不引入安装时重置、启动时接管遗留手动状态、SIGTERM 重置和高温期间失联立即交回系统的策略。现有高温保护、控制归属、失败恢复和断连保护继续保留。 |
| 运行日志 | 保留本项目异步写入、轮转、总容量限制和保留周期 | 不切换成上游 root 进程仅写统一日志的方案，不自动删除历史日志目录。 |
| 校准与录制 | 保留本项目实现 | 校准已有调用用户归属、降权文件访问和无效结果拒绝保存；录制已有容量限制、活动锁、到期与永久保留策略。上游 `UserData` 整体替换未引入，sudo 录制的默认目录行为也没有随本次改变。 |
| 配置测试 | 保留本项目实现 | 本项目已用临时目录测试配置读写，无需再引入重复测试。 |

DMG 仍由用户覆盖应用后通过设置窗口同步服务。图形授权取消、失败重试、后台文件回滚、禁止覆盖更高版本及 CLI 手动控制保护继续有效。Homebrew、直接下载、代理和源码更新入口保持兼容。
