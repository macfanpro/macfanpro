# DMG 安装与维护

DMG 是新增的发行格式，Homebrew、在线脚本、源码安装和原有 `.tar.gz` 布局继续保留。
从 `0.2.3.50` 起，发行附件提供 DMG 和首次启动向导。旧版 `0.2.3.37` 不包含这项功能。

## 普通用户

1. 国内下载不畅时，先开启浏览器可用的代理；终端的代理环境变量不会自动配置浏览器。
2. 下载发行页中的 `MacFanPro-<版本>-macos-arm64.dmg`，打开后将应用拖入“应用程序”。
3. 从“应用程序”打开，按向导点击“安装并启用”，在 macOS 系统弹窗中授权。
4. 如被 Gatekeeper 拦截，确认文件来源后，到“系统设置 → 隐私与安全性”处理首次打开。本项目目前沿用 ad-hoc 签名，尚未经过 Apple 公证。

后台服务程序与语言资源均内置，下载后首次安装不需要再次联网。密码由系统弹窗处理，应用不读取或保存密码。取消授权后可以重试。正常安装后可从菜单中的“后台服务…”重新打开向导。

更新：退出应用，拖入新版替换并重新打开。需要时授权同步服务。服务同步期间会短暂重启，随后应用恢复保存的模式；如果 CLI 正在保持手动转速，先由用户明确结束该控制，再执行服务替换。

卸载：打开“后台服务…”并选择“移除后台服务…”，确认恢复 macOS 自动控制，授权后退出，再将应用移入废纸篓。配置、校准与日志保留。仅拖入废纸篓不会移除独立安装的后台服务。

Homebrew 已管理该软件时，继续按照 Homebrew 指引更新或修复。向导不会自动切换安装渠道，也不会接管另一个账户所属的后台服务。

## 开发与打包

```bash
bash Scripts/test.sh --all-configurations
bash Scripts/check-localization-package.sh
bash Scripts/package-release.sh
```

打包不安装或启动应用，不修改本机后台服务。输出包含：

- 原有 `.tar.gz`、`SHA256SUMS`、`install.sh`、`install.sh.sha256`。
- 新增 `.dmg` 和单独的 `.dmg.sha256`。

`SHA256SUMS` 继续只列出旧安装器下载的 tar 包，避免已部署版本因缺少 DMG 而校验失败。
DMG 包含应用、“应用程序”链接和安装说明。应用内的 `Contents/Helpers/macfanpro` 与外部 CLI 来自同一次构建；许可文件一并打包。

GitHub Actions 随正常版本标签构建并上传 DMG 到草稿发行。发布前仍需下载发行附件验证，按既有发布流程发布；开发本功能不等于发布新版本。官网只在最新正式发行确实提供匹配 DMG 附件时显示 DMG 下载入口；请求失败时，现有下载入口与代理安装命令仍可用。

## 实现与权限

- 首次启动只探测服务。服务身份、控制账户和版本检查通过后，才启动应用的温控逻辑。
- 图形安装只能从 `/Applications/MacFanPro.app` 内的固定服务程序调用。DMG 挂载目录、其他路径及符号链接重定向均被拒绝。
- 特权 CLI 检查 root 权限、有效用户、应用签名、安装目录权限、Homebrew 管理状态和既有服务归属。
- 安装写入原有 root 所有的 CLI 与 LaunchDaemon 位置，不直接把用户可写的应用内部程序作为 root 后台服务启动。
- 图形服务安装不重复复制、删除正在运行的应用。失败时恢复旧服务文件，并尝试重新启动之前注册的服务；恢复失败会在诊断详情中明确记录。
- 服务成功返回后，应用还会独立检查实际运行版本，避免把授权完成当作安装完成。
- 图形卸载保留应用与用户数据，只有用户确认后才移除服务并恢复系统自动控制。

## 验收边界

自动化覆盖安装状态判断、授权取消/失败/重试、错误成功返回、服务归属和降级拒绝、文件恢复及符号链接保护，并用隔离环境渲染 18 种语言的浅色/深色向导。原有 Debug/Release、断连和在线安装器测试继续运行。

发布前需要在干净的 macOS 14+ 测试环境中验证真正的系统授权、首次安装、升级、取消授权和卸载；挂载 DMG 或模拟授权测试不能代替该检查。服务重启与风扇状态检查应在专用测试机/经用户同意的本机进行。
