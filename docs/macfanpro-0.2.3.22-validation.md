# MacFanPro 0.2.3.22 验证记录

## 修改范围

第三轮审计（针对 0.2.3.21，编号 F1–F10）确认的 10 个问题全部修复。逐项分析见 [风扇状态与校准修复](fan-state-fixes-20260927.md) 的 “Third review (0.2.3.22)” 一节。

- `Daemon.swift`：
  - 高温保护设满速与标记“保护中”在同一 `smcLock` 临界区内完成（F2）。
  - 看门狗在保护期间清除设定时也持有 `smcLock`（F1）。
  - 写入中途失败且没有已记录的设定时，交还自动控制，失败则每 5 秒重试（F3）。
- `ThermalMonitor.swift`：
  - `switchProfile` 增加可选的完成回调（F4）。
  - 95°C 保护保持到低于 90°C（F6）。
  - 计算用的时间单位跟随 `start(interval:)`（F10）。
- `ProfileSwitchGate.swift` / `AppState.swift`：
  - 切换状态机改为等监控在自己的队列里确认切换完成后再放行（F4）。
  - 监控发出的“恢复自动”失败后退避重试（F5）。
- `FanControl.swift`：设置全部风扇时，按每个风扇各自的范围限速（F7）。
- `MacFanPro.swift`：
  - 校准期间退出菜单栏应用、结束后重新打开；未通过校验的结果不保存；原子写入（F8）。
  - 安装预检与复制应用包时，按本次实际要安装的版本判断，包括较新的 Homebrew 版本（F9）。
  - `watch --interval` 拒绝非正数（F10）。
- 温控曲线和 95°C 安全阈值未改变。

## 本机候选版

环境：M4 Max MacBook Pro（Mac16,5），macOS 27.0，用 `./setup.sh` 安装候选代码。

- Debug、Release 各 125 项测试通过；各配置 108 次断连检查通过；编译无警告。新增：
  - 切换顺序测试（按监控确认切换的 token 放行）；
  - 用模拟 SMC 测试逐风扇限速；
  - 无效校准结果不覆盖旧文件的测试。
- 负载下 Smart 手动控制风扇（约 2000–2300 RPM）时按“默认”：约 4 秒内转为系统控制，此后保持系统控制，保存的模式为 Silent。
- 应用运行 Smart 时直接执行 `sudo macfanpro calibrate --mode quick --stress gpu`：
  - 校准开始即退出应用；100% 档位实际达到约 5770 RPM，未被应用改写；
  - 得到 6 个有效测量点，`calibration.json` 与 CSV 归用户所有；
  - 结束后应用自动重新打开并恢复 Smart，无校准被拒绝的日志。
- 未实机覆盖：
  - F1–F3 的时序与写入失败，无法人为触发，由代码审查覆盖；
  - F4、F6 需要温度达到 95°C，未刻意加热，由状态机测试与代码审查覆盖；
  - F9 需要已安装的 CLI 本身包含本修复，从下一次升级起才能实测；
  - F10 仅影响 `watch` 命令。
